# socompartido — Sistemas Operativos

Prácticas de FreeRTOS sobre ESP32 (marcapasos VVI).

| Carpeta | Tema |
|---|---|
| `practica-2/` | Syscalls: capa de llamadas al sistema y despachador `KernelService` |
| `practica-3/` | Context Switch: planificación apropiativa, ISR y afinidad de núcleo |

Cada carpeta tiene su `README.md` con el reporte, el código fuente y el `diagram.json` para simular en [Wokwi](https://wokwi.com/projects/new/esp32).

## Entregables y validación

- [Práctica 2 resuelta](practica-2/Practica2_Resuelta.pdf) y [Práctica 3 resuelta](practica-3/Practica3_Resuelta.pdf).
- Las capturas reales de Wokwi están en `practica-2/evidencias/` y `practica-3/evidencias/`.
- [Validación en Wokwi](VALIDACION_WOKWI.md) distingue los intentos de compilación de las pruebas de ejecución que aún faltan.
